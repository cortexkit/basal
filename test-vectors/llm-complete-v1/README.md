# Broca completion dollar-accounting vectors

These files are byte-for-byte copies of the `tool-result-v1/` catalog and replies
from Broca's `llm-complete-1124` sample bundle. Broca generated them in the
`llm_tools::complete::tests::route_replies_for_the_callers` test. The runtime
behind that test is a stand-in; the catalog and reply bodies come from Broca's
route serializer.

`SHA256SUMS` selects the four files used by Basal's dollar-accounting tests. The
source bundle's full checksum manifest has SHA-256
`e6b7c111273a20387a74c5183f1e1176080482ad7d32b25c26d31e3fa9654257`.
